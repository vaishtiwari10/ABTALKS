## Real-World AI Products

### 1. ChatGPT
- Input: User prompt
- Processing: Large Language Model
- Output: Human-like response

### 2. Google Translate
- Input: Text in one language
- Processing: Neural Machine Translation
- Output: Translated text

### 3. Spotify Recommendations
- Input: User listening history
- Processing: Recommendation algorithms
- Output: Personalized music suggestions

## How a Chatbot Works

A chatbot receives a user's message as input. It preprocesses the text to understand the user's intent. An AI model analyzes the request and predicts the best response. The response is formatted into natural language before being returned. This process happens within seconds, making the interaction feel conversational.
